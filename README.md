# 👁️ الهروب من الغرفة المظلمة (Escape the Dark Room)

لعبة رعب تفاعلية خفيفة تعمل مباشرة على المتصفح عبر GitHub Pages. تم تصميمها بلغات HTML و CSS و JavaScript خصيصاً لتمنحك أجواءً مليئة بالتوتر والغموض.

## 🕹️ قصة اللعبة
تستيقظ في مكان مظلم تماماً دون أن تذكر كيف وصلت إلى هناك. معك فقط كشاف يدوي قديم تبدأ طاقته بالنفاد تدريجياً، وعليك اتخاذ القرارات الصحيحة للبقاء على قيد الحياة والهرب قبل أن يسيطر الذعر عليك!

## ⚙️ مميزات اللعبة
* نظام تتبع طاقة الكشاف اليدوي (Battery Meter).
* مؤشر الذعر والرعب التفاعلي (Panic Gauge).
* مؤثرات صوتية وأجواء مرعبة تفاعلية.
* تصميم عصري داكن متوافق تماماً مع الهواتف الذكية والحواسيب.
